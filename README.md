# ردیاب موقعیت با پیامک (SMS Location Finder)

## این اپ چیکار می‌کند؟
وقتی از هر شماره‌ای، یک پیامک حاوی کلمه رمز مشخص (پیش‌فرض: `FINDME`) به این گوشی
فرستاده شود، اپ به‌صورت خودکار موقعیت GPS فعلی را می‌گیرد و با یک لینک گوگل‌مپ
به همان شماره پیامک می‌کند.

**نکته کلیدی:** این کار فقط به **آنتن‌دهی شبکه موبایل** نیاز دارد، نه به بسته
اینترنت (وای‌فای یا دیتا). یعنی حتی اگر دیتای گوشی خاموش باشد، تا وقتی گوشی
روشن است و آنتن دارد، کار می‌کند.

## ⚠️ محدودیت‌های واقعی که باید بدانی
1. **اگر گوشی خاموش باشد یا حالت هواپیما فعال باشد، هیچ راهی برای گرفتن موقعیت لحظه‌ای وجود ندارد.**
2. **این اپ باید از قبل نصب و راه‌اندازی شود** — یعنی همین حالا که گوشی دستت است.
   بعد از گم شدن گوشی نمی‌توانی آن را نصب کنی.
3. اندروید ۱۰ به بعد اجرای پس‌زمینه را محدود می‌کند؛ به همین دلیل این اپ از
   **Foreground Service** استفاده می‌کند که یک نوتیفیکیشن دائمی نشان می‌دهد
   (این طبیعی و لازم است، وگرنه سیستم سرویس را می‌کشد).
4. بعضی گوشی‌های چینی (شیائومی/هواوی/اوپو و غیره) بهینه‌سازی باتری تهاجمی دارند
   که ممکن است اپ‌های پس‌زمینه را ببندند. باید در تنظیمات باتری، این اپ را
   **"بدون محدودیت" (Unrestricted)** یا **"اجازه‌ی اجرای پس‌زمینه"** قرار دهی.
5. برای گرفتن موقعیت باید GPS/Location گوشی روشن باشد.

## ساخت APK بدون نصب هیچ برنامه‌ای (با GitHub Actions)
این پروژه شامل یک فایل آماده در `.github/workflows/build-apk.yml` است که
به‌صورت خودکار APK را برایت می‌سازد. مراحل:

1. یک ریپازیتوری جدید (خصوصی یا عمومی) در github.com بساز.
2. ⚠️ **نکته مهم و رایج‌ترین منبع خطا:** باید محتویات داخل پوشه
   `SMSLocationFinder` (یعنی فایل‌های `gradlew`, `build.gradle`, پوشه `app` و
   غیره) مستقیماً در ریشه ریپو قرار بگیرند — نه خودِ پوشه `SMSLocationFinder`
   به‌عنوان یک زیرپوشه. یعنی مسیر درست باید
   `نام-ریپو/gradlew` باشد، نه `نام-ریپو/SMSLocationFinder/gradlew`.

   ساده‌ترین راه برای رعایت این نکته موقع "Add file → Upload files":
   اول پوشه `SMSLocationFinder` را روی کامپیوترت باز کن، و به‌جای کشیدن
   خودِ پوشه، **فقط فایل‌ها و زیرپوشه‌های داخلش** (مثل `app`, `gradle`,
   `gradlew`, `build.gradle` و بقیه) را انتخاب و به صفحه گیت‌هاب بکش.
   (نسخه‌ی به‌روزشده‌ی این پروژه که برایت فرستادم، یک workflow مقاوم‌تر
   دارد که حتی اگر این اشتباه رخ دهد، خودش `gradlew` را در هر زیرپوشه‌ای
   پیدا می‌کند — پس اگر بازهم اشتباه آپلود کردی نگران نباش.)

   یا با git (این روش خودش تضمین می‌کند ساختار درست باشد):
   ```bash
   cd SMSLocationFinder
   git init
   git add .
   git commit -m "initial commit"
   git remote add origin <لینک ریپوی خودت>
   git push -u origin main
   ```
3. به تب Actions در صفحه گیت‌هاب ریپو برو. باید یک workflow به اسم
   "Build APK" را ببینی که به‌صورت خودکار اجرا شده (یا اگر نشد، دکمه
   "Run workflow" را بزن).
4. صبر کن (حدود دو تا پنج دقیقه) تا اجرا با علامت سبز تمام شود.
5. روی همان اجرا (run) کلیک کن، پایین صفحه بخش Artifacts را پیدا کن،
   و فایل SMSLocationFinder-debug-apk را دانلود کن. داخلش app-debug.apk است.
6. آن فایل APK را به گوشی‌ات منتقل کن (از طریق کابل، تلگرام به خودت، گوگل درایو
   و غیره) و رویش بزن تا نصب شود. ممکن است اندروید هشدار "منابع ناشناس" بدهد؛
   باید اجازه نصب از آن منبع را بدهی چون از گوگل‌پلی نیامده.

## ساخت خودکار APK با یک اسکریپت (بدون Android Studio)
دو اسکریپت آماده در این پروژه گذاشته شده که خودشان Android SDK حداقلی را
دانلود، نصب و APK را می‌سازند. فقط **Java (JDK 17)** باید از قبل روی
سیستمت نصب باشد (اگر نیست: https://adoptium.net).

### روی مک یا لینوکس
در ترمینال، داخل پوشه پروژه:
```bash
chmod +x build-apk.sh
./build-apk.sh
```

### روی ویندوز
روی فایل `build-apk.ps1` راست‌کلیک کن و **"Run with PowerShell"** را بزن.
یا در PowerShell:
```powershell
powershell -ExecutionPolicy Bypass -File .\build-apk.ps1
```

اولین اجرا کمی طول می‌کشد (دانلود حدود ۱۵۰-۳۰۰ مگابایت SDK حداقلی).
در پایان، مسیر فایل APK نمایش داده می‌شود:
```
app/build/outputs/apk/debug/app-debug.apk
```
این فایل را با کابل یا هر روش دیگری به گوشی منتقل کن و رویش بزن تا نصب شود
(اندروید ممکن است هشدار "منابع ناشناس" بدهد؛ اجازه نصب را بده چون از گوگل‌پلی نیامده).

### اگر با خطا مواجه شدی
- **"JAVA_HOME not set"** یا مشابه → Java (JDK 17) را نصب کن.
- **مشکل دسترسی به اینترنت / تایم‌اوت دانلود** → مطمئن شو فایروال یا VPN
  دسترسی به دامنه‌ی `dl.google.com` را مسدود نکرده.
- **"Permission denied" روی مک/لینوکس** → مطمئن شو `chmod +x build-apk.sh`
  و `chmod +x gradlew` را زده‌ای.

## نصب (روش جایگزین: مستقیم در Android Studio)
1. Android Studio را نصب کن (رایگان، از سایت رسمی گوگل).
2. این پوشه پروژه را در Android Studio باز کن (`Open` → مسیر این پوشه).
3. صبر کن تا Gradle Sync تمام شود (نیاز به اینترنت دارد، فقط برای دانلود کتابخانه‌ها).
4. گوشی‌ات را با کابل USB وصل کن و **USB Debugging** را در تنظیمات
   Developer Options فعال کن.
5. دکمه Run (▶) را در Android Studio بزن تا اپ روی گوشی نصب شود.

## راه‌اندازی روی گوشی
1. اپ را باز کن.
2. کلمه رمز دلخواهت را وارد و ذخیره کن (یا `FINDME` را نگه دار).
3. دکمه «اعطای مجوزها» را بزن و همه مجوزها (پیامک + مکان) را قبول کن.
4. دکمه «اجازه مکان در پس‌زمینه» را بزن و گزینه **"Allow all the time"** را انتخاب کن.
5. در تنظیمات گوشی، بهینه‌سازی باتری برای این اپ را غیرفعال کن
   (Settings → Apps → SMS Location Finder → Battery → Unrestricted).

## استفاده (وقتی گوشی گم شد)
از هر گوشی دیگری (یا خط دیگر)، به شماره گوشی گم‌شده پیامک بفرست:
```
FINDME
```
(یا هر کلمه رمزی که تنظیم کردی). در عرض چند ثانیه تا چند دقیقه، یک پیامک
پاسخ با لینک نقشه گوگل دریافت می‌کنی.

## توصیه‌های امنیتی
- کلمه رمز را چیزی ساده مثل "FINDME" نگذار؛ یک رمز شخصی و غیرقابل‌حدس انتخاب کن،
  وگرنه هرکسی می‌تواند موقعیت گوشی‌ات را دربیاورد.
- این کد فقط برای گوشی خودت است. نصب مخفیانه چنین اپی روی گوشی دیگران بدون
  اطلاع و رضایت آن‌ها در بسیاری از کشورها **غیرقانونی** است (قوانین جاسوسی/حریم خصوصی).
- به‌عنوان پشتیبان، حتماً **Find My Device گوگل** را هم فعال نگه دار
  (Settings → Google → Find My Device) — این سرویس رسمی گوگل است و اغلب
  دقیق‌تر و پایدارتر از هر راه‌حل خانگی عمل می‌کند.
